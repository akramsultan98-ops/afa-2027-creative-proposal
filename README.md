# AFA 2027 — Creative Experience Proposal V2

Interactive proposal concept for the AFA 33rd Annual International Fertilizer Conference & Exhibition 2027.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

Example:
```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Source basis
- Creative Studio Project Brief — Final
- AFA Proposal Design PDF
- AFA Event Production Tender Requirements 2027

## Direction
Growing the Future — a visual narrative moving from Nourish → Grow → Connect → Build, then translating the identity into physical and digital event experience.
